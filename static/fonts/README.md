Fonts bundled so teacher-only PDF reports render both Chinese and Latin
on Linux and PythonAnywhere without relying on system font packages.

- DroidSansFallbackFull.ttf — Droid Sans Fallback (Apache License 2.0). CJK coverage.
- DejaVuSans.ttf — DejaVu Sans (Bitstream Vera license; DejaVu changes are public domain). Latin coverage.

Droid Sans Fallback does not include ASCII, so both files are required.
